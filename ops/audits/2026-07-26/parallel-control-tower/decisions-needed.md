recommendations do not satisfy them.

   preserved provider session. It authorizes cleanup only.

   for one new disposable meeting, one operator host, fictional Student 1, one

   prerequisite set, immutable candidate and rollback evidence, and a new
   narrow production decision. Prior controlled-pilot intent is not a release
