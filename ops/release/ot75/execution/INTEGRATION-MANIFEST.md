# OT-75 Integration Manifest

OT-75 is a preparation-only packet. It does not integrate runtime code.

## Included

- Static release readiness contracts.
- Observability contracts.
- Feature-local deployment descriptors.
- Runbooks.
- Static scripts and release-only tests.
- Unique OT-75 validation workflow.

## Excluded

- App runtime wiring.
- Current worker startup changes.
- Root package script changes.
- Root deployment descriptor changes.
- Database migrations.
- Provider code changes.
- Auth, CRM, domain, AppShell, and shared-barrel changes.
