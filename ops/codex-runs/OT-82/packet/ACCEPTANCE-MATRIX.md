## Result recording contract

`ops/evidence/ot-82/acceptance/acceptance-results.json` must contain one object per ID with `status`, `commands`, `exitCodes`, `evidence`, and `notes`. Allowed statuses are `pass`, `fail`, `blocked`, and `not_run_waiting_for_base`. The Markdown companion must summarize the same data without changing status semantics.
