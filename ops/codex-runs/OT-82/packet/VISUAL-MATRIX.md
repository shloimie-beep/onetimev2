# OT-82 Visual and Interaction Matrix

## Harness contract

- Browser: Chromium.
- Device scale factor: 1.
- Required viewport presets: `360x800`, `390x844`, `768x1024`, and `1440x1000`.
- Use seeded synthetic/local fixtures only. Protected pages must not use production sessions or data.
- Wait for `document.fonts.ready` and for the surface-specific ready marker.
- Freeze screenshot time before the campaign deadline. Test deadline hiding separately with a post-deadline clock.
- For default screenshots, make moving animation position deterministic without changing product behavior; separately assert that motion-enabled mode has the approved animation.
- Screenshot comparisons use a maximum changed-pixel ratio of `0.005`. A larger difference requires an intentional baseline update documented in `visual-index.md`.
- Full-page screenshots prove page composition. Viewport screenshots prove top-fold, focus, overlays, reduced motion, and zoom behavior.
- Every screenshot row also asserts `document.documentElement.scrollWidth <= document.documentElement.clientWidth`.
- Store screenshots only at the exact paths below.
- A non-shipping component fixture may be used for the shared Dialog. It must live under `tests/fixtures/brand-system/`, must not be routed or bundled in production, and must use the canonical package.
- RTL checks set `document.documentElement.dir = "rtl"` without inventing translated product copy.
- The 200% checks must use actual browser zoom when available. A CDP page-scale or equivalent effective CSS-pixel viewport is acceptable only when the report records the mechanism and proves reflow.
- Contrast is reported in `ops/evidence/ot-82/accessibility-report.json`; no screenshot substitutes for measured contrast.
- Drawer and Dialog rows are incomplete without keyboard tests for trigger focus, initial focus, Tab/Shift+Tab trap, Escape close, overlay close where applicable, body scroll lock, and focus restoration.

## Behavioral checks without separate screenshots

The visual suite must also record these checks in `ops/evidence/ot-82/interaction-report.json`:

1. `/` contains one canonical ticker shell before deadline; every other built route contains zero.
2. The motion-enabled ticker has a non-`none` animation and the reduced-motion ticker has `animation-name: none`.
3. The landing hero/ticker visible text contains none of `$67`, `monthly price`, `trial`, or `No card today`.
4. Every visible enabled button/link on each primary surface changes route, submits, opens/closes an overlay, filters, retries, or invokes a supplied callback. Controls without behavior are absent or explicitly disabled with an accessible reason.
5. Public and authenticated drawers use the same canonical Drawer contract even though shell composition differs.
6. The shared Dialog is not shipped as a production-only demonstration route.
7. Tables expose headers and remain usable at mobile widths through the canonical responsive contract.
8. Form errors are associated with fields and focus moves to the first relevant error.
9. Loading, empty, and error transitions retain a logical focus target and announce status appropriately.
10. Every request made while producing the matrix is classified; BNA, Operations, provider, production, and external-font requests total zero.
