# Batch 01 package index

Every package contains the required brief, source manifest and selects, 20
edit-ready clean clips, a locked 30-second sequence, CapCut instructions, a
natural-language prompt, captions, nine static derivatives, caption/alt/CTA
copy, rights and blocker records, a preview contact sheet, and a decision log.

The nine static outputs per package are:

- photo-led hook card at 1080×1350;
- proof card at 1080×1350;
- square backup at 1080×1080;
- Story asset at 1080×1920;
- cover/thumbnail at 1280×720;
- four-panel 1080×1350 carousel.

All rendered statics use original Rabbi-only pixels. Student images are excluded.
All visible CTAs remain `CTA — VERIFY BEFORE EXPORT`.
