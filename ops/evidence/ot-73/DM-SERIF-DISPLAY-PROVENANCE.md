# DM Serif Display Provenance

OT-73 self-hosts DM Serif Display for landing wordmark, hero, and major section
headings.

## Asset

- Local WOFF2: `apps/web/public/assets/fonts/dm-serif-display-latin.woff2`
- Local license text: `apps/web/public/assets/fonts/dm-serif-display-OFL.txt`
- Runtime CSS source: `apps/web/src/client/public/styles.css`
- Runtime behavior: no third-party font request; CSS loads the local WOFF2.

## Source

- Google Fonts specimen: `https://fonts.google.com/specimen/DM+Serif+Display`
- Google Fonts CSS delivery URL used to identify the Latin WOFF2:
  `https://fonts.googleapis.com/css2?family=DM+Serif+Display&display=swap`
- Downloaded WOFF2:
  `https://fonts.gstatic.com/s/dmserifdisplay/v17/-nFnOHM81r4j6k0gjAW3mujVU2B2G_Bx0g.woff2`
- License text downloaded from Google Fonts GitHub:
  `https://raw.githubusercontent.com/google/fonts/main/ofl/dmserifdisplay/OFL.txt`
