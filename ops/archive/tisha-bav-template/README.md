# Dormant Tisha B’Av historical funnel template

This directory is an archive, not a product route or provider command. It
records the historical 2026 asset identities so a same-name workflow or
campaign cannot be silently reused. Its manifest requires zero new enrollment,
zero new send, no product access, and no conversion of event-only consent.

The archive contains no secret, audience, recipient, child record, meeting
link, or provider bearer. A future event must be copied into a newly named
artifact with new identifiers, dates, consent text, approved copy, route
review, and explicit provider authority. Nothing in this directory can
activate, publish, enroll, or send.

The terminal browser response is implemented in the P35 domain-transition
feature. Historical form and API requests return `410 Gone` and perform no
write. Central removal of the old active route and build registrations is
requested through P35’s structured route steward request.
